# AwesomePet - Serviços para Pets

Website para um serviço completo de cuidados com animais de estimação.

## 📁 Estrutura do Projeto

```
📦 Projeto-Teste-IBM/
├── 📄 index.html          # Página principal
├── 📁 css/                # Folhas de estilo
│   └── styles.css
├── 📁 pages/              # Páginas de serviços
│   ├── banho-tosa.html
│   ├── hotel.html
│   └── veterinario.html
└── 📄 README.md           # Este arquivo
```

## 🎯 Páginas

- **index.html** - Página inicial com apresentação dos serviços
- **pages/banho-tosa.html** - Serviço de banho e tosa
- **pages/hotel.html** - Serviço de hotel para pets
- **pages/veterinario.html** - Serviço veterinário

## 🎨 Estilos

Todos os arquivos utilizam:

- **Bootstrap 5.3.3** - Framework CSS
- **styles.css** - Estilos customizados

## 🚀 Como usar

1. Abra `index.html` no navegador
2. Use o menu para navegar entre os serviços
3. Clique nos cards de serviços para ver as páginas específicas
